# MCU Tracker

Track your journey through the Marvel Cinematic Universe: films, TV series, one-shots, specials, animated series, and everything in between.

## What it does

- Browse every MCU title in **Release Date Order** or **Chronological Order**
- Filter by type: films, TV series, one-shots, and more
- Track watch status down to the **individual episode level**
- Build a personal **watchlist** with pace tracking and a countdown to the next release
- View titles grouped by **franchise** (Iron Man, Thor, Avengers, etc.)
- Track non-MCU Marvel titles (X-Men, Spider-Man, Deadpool, etc.) in **Other Universes**
- Sign in with **Google**: no passwords, no account setup needed
